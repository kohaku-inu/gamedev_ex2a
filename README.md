## מטלה 2 חלק א
א -
ביוניטי, גודל המצלמה קובע את יחידות גובה (יחידת מרחק ב"עולם המשחק") שצריך לגובה המסך (שנראה לשחקן) והיא שומרת שאותו מספר יחידות יהיה מלמעלה עד למטה כדי למלא את גובה המסך, אם גודל המצלמה הוא 5 אז גובה המסך צריך להיות 10 יחידות בכל מסך שמציג את המשחק. אם מסובבים לתצוגה אנכית מאופקית גדל מספר הפיקסלים ל"גובה המסך", וחייב להיות מיוצג ב10 יחידות גובה, כל יחידה גובה מייצגת יותר פיקסלים (שהם גודל קבוע אז היחידות גדלות) וככה גם כל אובייקט שמוצג במשחק בהתאמה ליחידות הגובה שלו גם יגדל.
ב -
הפתרון קובץ סקריפט "CameraFitModes.cs". הסקריפט מכיל 3 דרכים לשינוי התצוגה:
- קיבוע גובה - המצב הזה הוא ברירת המחדל, הגובה חייב להיות 10 יחידות, גורם להגדלת האובייקטים בתצוגה אנכית Size = height ÷ 2 
- קיבוע רוחב - במצב הזה רוחב המשחק קבוע ל10 יחידות, הגובה משתנה, יוצר אפקט הפוך והאובייקטים יראו קטנים יותר. Size = width ÷ (2 × aspect)
- גודל האובייקטים קבוע - משאיר את האובייקטים בגודל קבוע, גובה ורוחב המסך והמצלמה משתנים בהתאם. Size = 0.5 × √(area ÷ aspect)
